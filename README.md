# DevOps Week 2 - Git & GitHub

## Overview

This repository demonstrates the Week 2 DevOps Internship tasks related to Git, GitHub, version control, branching, merging, README documentation, and `.gitignore`.

## Objectives

- Understand Git and GitHub
- Configure Git
- Create and clone a repository
- Track files using Git
- Stage and commit changes
- Push changes to GitHub
- Create and merge branches
- Use `.gitignore`
- Maintain professional project documentation
